## 약점
1. **그래프 이동 방향**(7번): 그림은 그렸지만 공급↑·수요↓에서 가격 방향을 반대로 판단.
2. **분류표 문항**(2, 12): 질문 → 예/아니요 → 재화 종류 대응을 한 단계씩 확인하지 않음.
3. **서술형 요소 누락**(서1, 서4): 두 개 묻는데 하나만 쓰는 패턴. 서4는 문제에 "역선택과 도덕적 해이 **각각**"이라고 있었음.

## 공부법
- **수요·공급 이동표 암기**: 수요↑(P↑Q↑) / 수요↓(P↓Q↓) / 공급↑(P↓Q↑) / 공급↓(P↑Q↓). 두 개가 동시에 움직이면 **같은 방향인 것만 확정**, 반대인 쪽은 "불분명".
- **재화 분류 2×2 표**: 경합성 × 배제성 → 사적재 / 공유자원 / 클럽재 / 공공재. "무임승차 = 배제 불가", "공유지의 비극 = 경합 O + 배제 X".
- **서술형 체크**: 문제에서 "~과 ~", "각각", "내용과 이유"를 찾아 동그라미 → 동그라미 개수만큼 답이 있는지 확인.
- **교과서 사례 정리**: 정책 실패 사례(비정규직 2년 규제 등)는 "내용 → 기업의 반응 → 결과(역효과)" 3줄로.
