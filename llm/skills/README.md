# 범용 Claude 스킬

과목과 상관없이 쓰는 스킬입니다. 원래 [pwh831/Japan](https://github.com/pwh831/Japan)의 `.claude/skills/`에 있던 것을 옮겨 왔습니다.

| 스킬 | 하는 일 |
|---|---|
| `critique` | 코드나 계획을 통과·실패 두 가지로만 판정하는 적대적 점검 |
| `grilling` | 계획·결정·아이디어를 결정 트리로 나눠 끝까지 캐묻는 인터뷰 |
| `grill-me` | `grilling`을 부르는 단축 명령 |
| `log` | 이번 세션의 critique 점검 기록 보기 |

쓰려면 폴더를 작업할 저장소의 `.claude/skills/` 아래로 복사하세요.
