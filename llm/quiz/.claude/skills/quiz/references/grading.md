# 서답형 채점

'이름 쓰기'만 기계가 채점한다. 나머지는 고르거나(선택형) 스스로 매긴다(떠올리기).

채점은 **너그럽되 새어 나가지 않게** 해야 한다. 너무 빡빡하면 아는데 틀렸다고 나와
사용자가 앱을 안 믿게 되고, 너무 무르면 모르는데 맞았다고 나와 시험장에서 틀린다.

## 언제나 무시하는 것

`norm()` 이 답과 정답 양쪽에 똑같이 건다.

- 대소문자
- 공백·가운뎃점·쉼표·마침표·붙임표·밑줄·따옴표
- **괄호와 그 안의 내용** — `클로즈업(C.U.)` = `클로즈업`

## suffixes — 꼬리말

`SUBJECT.suffixes` 에 적은 꼬리말은 **있으나 없으나 정답**이다.

```js
suffixes: ["기법", "효과", "법"]     // '몽타주 기법' = '몽타주'
```

지리에서는 `시·군·도·강·섬·반도·해협`, 문학·영상에서는 `기법·효과·법` 이 이에 해당한다.

긴 것부터 지우므로 `특별자치도` 가 `도` 보다 먼저 걸린다. 꼬리말은 **정답 쪽에도 답 쪽에도**
적용하므로 `반영` 을 써도 `반영론` 이 맞고, `반영론` 을 써도 `반영론` 이 맞다.

## equiv — 표기만 다른 같은 말

각 묶음의 **첫 낱말로 모은다.**

```js
equiv: [["쇼트", "숏", "샷"], ["미장센", "미쟝센"]]
```

`아이 레벨 샷` 도 `아이 레벨 쇼트` 도 같은 답이 된다. 항목마다 `aliases` 를 다 적는 대신
과목 전체에 한 번 거는 규칙이다.

`aliases` 와 다른 점: `aliases` 는 **그 항목의** 다른 이름이고, `equiv` 는 **과목 전체의**
표기 차이다. `C.U.` 는 `aliases`, `샷`/`쇼트` 는 `equiv` 다.

## 오타 한 글자

편집 거리 1이면 "정답 · 오타" 로 쳐 준다. 손으로 쓸 때의 실수까지 오답으로 잡으면
공부가 아니라 타자 연습이 된다.

**단, 서로 한 글자 차이인 이름들은 여기서 빠진다.** `반영론`/`표현론`,
`페이드인`/`페이드아웃` 같은 짝에서 오타를 봐주면 한쪽을 쓰고 다른 쪽 정답을 받는다.
엔진이 시작할 때 항목 이름을 전부 대조해서 **그런 이름을 자동으로 찾아내** 오타 관용에서
뺀다(`TIGHT`). 데이터에 따로 적을 것은 없다.

세 글자 미만인 이름도 오타를 안 봐준다 — 두 글자에서 한 글자가 틀리면 다른 말이다.

## 봐주면 안 되는 것

과목에 따라 **틀린 것을 틀렸다고 해야 하는** 지점이 있다. 지금 엔진에 들어 있지 않으므로,
필요하면 엔진을 고치고 그 이유를 여기 적는다.

- 일본어: 히라가나/가타카나 구분, 촉음 `っ`, 장음 `ー`, 탁점 — 글자 하나가 다른 단어다
  (`Japan` 저장소가 이것을 따로 다룬다)
- 한자·영문 표기가 정답인 과목: `norm()` 의 소문자 변환만으로는 모자랄 수 있다

## 확인하는 법

의심스러우면 `node` 로 직접 물어본다. 데이터 파일만 있으면 되고 브라우저는 필요 없다.

```bash
node -e '
const {SUBJECT,ITEMS}=require("./data/items.js");
const eq=SUBJECT.equiv||[], sf=(SUBJECT.suffixes||[]).sort((a,b)=>b.length-a.length);
const norm=s=>{s=String(s||"").toLowerCase().replace(/\(.*?\)/g,"").replace(/[\s·,.\-_]/g,"");
  for(const g of eq) for(let k=1;k<g.length;k++) s=s.split(g[k].toLowerCase()).join(g[0].toLowerCase());
  return s;};
const strip=s=>{for(const x of sf) if(s.length>x.length&&s.endsWith(x)) return s.slice(0,-x.length); return s;};
const hit=w=>ITEMS.filter(i=>[i.name,...(i.aliases||[])].map(norm).flatMap(c=>[c,strip(c)])
  .some(c=>c===norm(w)||c===strip(norm(w)))).map(i=>i.name);
for(const w of process.argv.slice(1)) console.log(w, "→", hit(w));
' 클로즈업 "클로즈 업" 반영론 반영
```

두 항목이 같이 나오면 답이 둘이라는 뜻이다. `aliases` 나 `suffixes` 를 좁혀야 한다.
