# 다섯 유형

유형은 데이터에 적지 않는다. **엔진이 같은 항목에서 다섯 가지를 만들어 낸다.**
그래서 데이터를 한 번 잘 쓰면 다섯 방향으로 외워진다. 반대로 데이터가 부실하면
다섯 유형이 전부 같이 부실해진다.

| 유형 | 묻는 것 | 쓰는 데이터 | 없으면 |
|---|---|---|---|
| 이름 쓰기 | 단서 → 이름 **타이핑** | `media` 또는 고유한 `features` 하나 | 출제 안 됨 |
| 설명 고르기 | 이름 → 옳은 서술 5지선다 | `features` + 남의 `features` 4개 | 보기가 줄어든 채 나감 |
| 설명 → 이름 | 서술 → 이름 5지선다 | 고유한 `features` + 남의 `name` 4개 | 보기가 줄어든 채 나감 |
| O·X 판별 | 붙여 준 서술이 이 항목 것인가 | `features` + 남의 `features` | O만 나옴 |
| 떠올리기 | 보지 않고 떠올린 뒤 확인 | `features` 전부 | 출제 안 됨 |

'혼합'을 고르면 매 문항 이 다섯에서 무작위로 고른다. 서술이 없는 항목(그림만 있는 항목)은
'이름 쓰기'로만 나간다.

---

## 이름 쓰기 — 이 앱의 핵심

고르는 것으로는 시험에서 못 쓴다. **직접 타이핑해서 틀리는 것을 확인하는 것**이
종이 교재와 다른 유일한 점이다.

- `media` 가 있으면 그림이 단서다 (지도 위의 번호나 마커)
- 없으면 **그 항목에만 있는 서술**을 단서로 고른다. 여러 항목이 공유하는 서술은
  답이 둘이 되므로 뒤로 미룬다
- 채점은 `grading.md` 의 규칙을 따른다

## 설명 고르기

정답 보기는 그 항목의 `features` 중 하나, 오답 보기 4개는 **다른 항목의 `features`** 다.
지어내지 않는다 — 전부 자료에 있는 진짜 문장이므로 틀린 보기도 공부가 된다.

오답을 길어오는 순서: **`confuse` → 같은 갈래 → 같은 영역 → 전체.**
정답 항목이 실제로 가진 서술과 겹치는 문구는 뺀다 (답이 둘이 되지 않게).

채점 뒤에는 각 오답 보기 밑에 **그 문장의 진짜 주인**을 적어 준다. 이게 은근히 크다 —
한 문제에서 다섯 항목을 본다.

## 설명 → 이름

단서는 **그 항목에만 있는 서술**을 먼저 고른다. 같은 서술을 가진 항목은 보기에서 뺀다.
보기 이름 4개도 `confuse` → 같은 갈래 → 같은 영역 → 전체 순으로 길어온다.

## O·X 판별

절반은 그 항목의 진짜 서술(→ O), 절반은 **다른 항목의 서술**을 가져다 붙인다(→ X).
붙여 오는 서술도 `confuse` 에서 먼저 고른다.

틀렸을 때 **그 문장의 진짜 주인이 누구인지** 알려 준다. 기출이 '자료 속 오류 찾기'나
'진술 O·X 채점'으로 나오는 과목에서 이 유형이 제일 실전에 가깝다.

## 떠올리기

이름만 보여 주고 "이 항목의 설명 N가지를 떠올려 보세요" → 확인 → 다 떠올렸는지 자가 채점.
`features` 가 2~4개일 때 제일 잘 돈다. 하나면 시시하고, 다섯이 넘으면 못 떠올린다.

---

## 좋은 서술의 조건

1. **이름이 안 들어간다** — "몽타주는 쇼트를 이어 붙여…" 는 못 쓴다
2. **한 문장에 한 가지** — O·X 에서 반만 맞는 문장이 되면 안 된다
3. **그 항목에만 해당한다** — 여러 항목에 해당하면 답이 둘이 된다
4. **자료의 말로 쓴다** — 시험은 자료의 표현으로 나온다

`verify.js` 가 1·3·4 중 기계로 볼 수 있는 것을 잡아 준다. 2는 사람이 봐야 한다.

## confuse 를 어디에 거나

**"시험에 나오면 둘 중 뭔지 헷갈릴 짝"** 에 건다. 교재가 나란히 놓고 비교시키는 것이
제일 확실한 신호다 — 붙여 놓고 비교시키는 건 내겠다는 뜻에 가깝다.

- 크기·정도만 다른 것: 롱 쇼트 / 풀 쇼트, 하이 앵글 / 버즈 아이 뷰
- 방향만 다른 것: 팬 / 틸트, 페이드인 / 페이드아웃
- 이름이 닮은 것: 반영론 / 표현론 / 효용론
- 헷갈리는 상위어–하위어: 신 / 시퀀스

**양방향으로 건다.** 한쪽만 걸면 반대 방향 연습이 빠진다 (`verify.js` 가 WARN 으로 잡는다).
