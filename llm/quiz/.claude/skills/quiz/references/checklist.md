# 넘기기 전 점검

빌드가 통과했는데 화면이 죽어 있던 적이 있다. 아래를 다 확인하기 전에는 끝났다고 하지 않는다.

## 1. 데이터

```bash
cd subjects/<과목>
node verify.js
```

- [ ] ERROR 0개
- [ ] WARN 을 하나씩 읽고, 남기는 것은 **왜 남기는지 말할 수 있다**
- [ ] 항목 수가 학습지에서 센 것과 맞는다 (`verify.js` 가 단원별로 세어 준다)
- [ ] 시험 범위 밖 단원이 `exam:false` 로 표시되어 있다

## 2. 빌드

```bash
python3 build.py
```

- [ ] "문법 검사 통과" 가 뜬다
- [ ] 산출물 크기가 그럴듯하다 (그림 없는 과목이 몇 MB면 뭔가 잘못됐다)
- [ ] `grep -c 'script src=' <산출물>` 이 0 이다

## 3. 기계가 보는 것

```bash
node smoke.js       # playwright 가 없으면 조용히 건너뛴다
```

다섯 유형이 다 나오는가 · 보기가 5개인가 · 세션이 결과 화면까지 가는가 ·
진도가 새로고침을 넘어 남는가 · 390px 에서 가로 스크롤이 안 생기는가 ·
페이지 오류가 없는가(글꼴 CDN 실패는 뺀다) 를 본다.

Playwright 가 없으면:

```bash
npm i -D playwright && npx playwright install chromium
```

## 4. 사람이 보는 것

기계가 못 보는 것이 남아 있다. 산출물 HTML 을 브라우저로 연다.
**`index.html` 말고 산출물을** 연다 — 사용자가 받는 것이 그것이다.

- [ ] 홈 화면에 단원·갈래가 다 보이고 항목 수가 맞는다
- [ ] 갈래를 켜고 끄면 '시작하기'의 문항 수가 따라 바뀐다
- [ ] **문제문이 말이 된다** — `kind`·`what` 이 갈래마다 어색하지 않은가
- [ ] 서답형에 진짜 정답을 쳐서 정답으로 판정된다
- [ ] 한글을 조합하는 중에 누른 Enter 가 문제를 건너뛰지 않는다
- [ ] 오답 보기가 정말 그럴듯하다 (아무 갈래에서나 온 엉뚱한 문장이 아닌가)
- [ ] 오답을 하나 만들고 결과 화면에서 '틀린 것만 다시 풀기'가 그것을 낸다
